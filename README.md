# Collegewebsiteforjivanjoti — XYZ Nursing College Website

A modern, premium, and fully responsive landing page website for **XYZ Nursing College** (Jivan Jyoti). This website is built to highlight the college's academic programs, campus life, admissions, faculty, facilities, and excellent placement records with high visual appeal, rich animations, and dark mode support.

---

## 🌟 Key Features

- **📱 Fully Responsive Design**: Seamless user experience across mobile, tablet, and desktop devices using Bootstrap 5's grid system combined with custom CSS.
- **🌗 Native Dark Mode**: An interactive, smooth dark mode theme toggle with user preference persistence.
- **✨ Rich Micro-Animations**:
  - Interactive page loader.
  - Animate on Scroll (AOS) for smooth content reveals.
  - Interactive counter stats on the hero section.
  - Dynamic scroll progress indicator.
- **🔍 Instant Search Overlay**: An interactive search feature to quickly find courses, events, or general info.
- **🖼️ Filterable Gallery**: A beautiful media gallery categorized by campus life, labs, events, and classroom activities, complete with a lightbox preview (using Glightbox).
- **📋 Online Admissions Portal**: A clean, validated form allowing prospective students to request information or apply online.
- **📍 Google Maps Integration**: Embedded interactive location details.

---

## 🛠️ Technology Stack

- **Markup & Structure**: HTML5 (Semantic elements, SEO optimized)
- **Styling**: Vanilla CSS3 (Custom variables, glassmorphism, responsive queries)
- **Frameworks & Layouts**: Bootstrap v5.3.2
- **Logic & Interactions**: Vanilla JavaScript (ES6+)
- **Icons**: Font Awesome v6.5.1
- **Animations**: AOS (Animate on Scroll) v2.3.1
- **Interactive Lightbox**: Glightbox

## 🚀 Getting Started

### Prerequisites
You only need a modern web browser to view and interact with the website locally.

### Local Setup
1. Clone the repository to your local machine:
   ```bash
   git clone https://github.com/mayankpatel61/Collegewebsiteforjivanjoti.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Collegewebsiteforjivanjoti
   ```
3. Open `index.html` directly in your browser:
   - On macOS: `open index.html`
   - On Windows: `start index.html`
   - Or run it using a local development server like VS Code's "Live Server".
